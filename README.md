# Kadosh POS

Sistema profesional de gestión para tienda de ropa urbana Kadosh.

## Stack principal

- Frontend: Next.js + TypeScript + Tailwind CSS + shadcn/ui
- Backend: Python + FastAPI
- Base de datos: Supabase PostgreSQL
- Realtime: Supabase Realtime
- Pagos: Culqi API
- ORM: SQLAlchemy
- Migraciones: Alembic
- Reportes: pandas + numpy
- Deploy: Vercel

## Objetivo

Construir un sistema de punto de venta con gestión de productos, variantes, inventario, clientes, ventas, pagos, sesiones de pago en tablet, reportes y seguridad basada en roles.

## Módulos principales

- Autenticación
- Usuarios y roles
- Categorías
- Productos
- Variantes de producto
- Inventario
- Clientes
- Ventas
- Pagos
- Sesiones de pago con Supabase Realtime
- Reportes
- Auditoría
